## [0.1.0] - 2026-09-14

### Added
- Initial release of Luxe personal finance dashboard
- Vanilla JS (ES modules) SPA with hash-based routing
- Dashboard view with spending visualization (Chart.js)
- Transactions page with CRUD operations and inline editing
- Budgets page with budget tracking
- Reports page with financial summaries
- Settings page for preferences and theme management
- localStorage persistence for transactions, budgets, and settings
- Dark mode with charcoal (#0B0B0D) base and emerald (#22C55E) accents
- CSS-only backgrounds with radial gradients and patterns
- Event bus (pub/sub) for cross-module communication
- Puppeteer-based smoke test suite
